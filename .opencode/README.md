# Guia de Utilização dos Agentes OpenCode

Este diretório contém a arquitetura multiagente do projeto da SPA de barbearia.

## Objetivo

Padronizar o uso dos agentes no OpenCode para planejamento, implementação, revisão e validação das tarefas do projeto, mantendo:
- rastreabilidade;
- separação de responsabilidades;
- aderência ao PRD;
- aderência à especificação funcional;
- menor risco de mudanças fora do escopo.
